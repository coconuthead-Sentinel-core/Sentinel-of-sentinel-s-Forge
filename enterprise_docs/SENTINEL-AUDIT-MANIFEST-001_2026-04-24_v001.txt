────────────────────────────────────────────────────────────────────────────────
FILE: /backend/core/security.py
────────────────────────────────────────────────────────────────────────────────
  Purpose:        Security guards, access controls, and rate limiting
  Framework:      FastAPI dependency injection; Starlette request handling
  Key Functions/Classes:

  api_key_guard(x_api_key: Optional[str]) -> None
    Description:  Validates X-API-Key header for protected endpoints
    Behavior:     - Production + key configured + valid key = ALLOW
                  - Production + key configured + invalid/missing = HTTP 401
                  - Production + key NOT configured = HTTP 503
                  - Development + key not configured = ALLOW (dev convenience)
    Used On:      All cognition, sync, glyph, and operational routes

  admin_guard(x_api_key: Optional[str]) -> None
    Description:  Guard for destructive/admin endpoints
    Behavior:     Delegates to api_key_guard(); always enforces API key
    Used On:      Admin-tier routes (DELETE /api/cog/memory, POST /api/stress)

  websocket_require_api_key(ws: WebSocket) -> None
    Description:  Enforces API key authentication for WebSocket connections
    Behavior:     - Checks ws.headers.get("x-api-key") first
                  - Falls back to ws.query_params.get("api_key")
                  - Raises HTTP 401 if neither valid
    Used On:      /ws/sync WebSocket endpoint

  class RateLimiter:
    Description:  Token bucket rate limiter; in-memory, per-client-IP
    Algorithm:    Token bucket (refill at RPM/60 per second; cap at BURST)
    Storage:      self._buckets: Dict[str, Dict[str, float]]
                  Key = client IP string; Value = {tokens: float, ts: float}
    __init__():   Reads settings.RATE_LIMIT_ENABLED, .RATE_LIMIT_RPM,
                  .RATE_LIMIT_BURST at instantiation
    __call__(request: Request) -> None:
                  Executes rate check per request; raises HTTP 429 if
                  token bucket exhausted
    _key(request): Extracts client IP from request.client.host

  Security Audit Status: CRITICAL gaps resolved (hardcoded key removed,
    CORS locked, guards applied to all applicable routes)
  Compliance Refs:
    - NIST AI RMF MANAGE (rate limiting as availability control)
    - ISO 27001 A.8.5 (Secure Authentication)
    - SOC 2 CC6.6 (External Threat Controls)

Directory: /backend/domain/

This directory contains pure domain models: data entities representing core
business objects. Domain models have no database aliases or framework coupling
(pure Pydantic models).

────────────────────────────────────────────────────────────────────────────────
FILE: /backend/domain/models.py
────────────────────────────────────────────────────────────────────────────────
  Purpose:        Core domain entity definitions (pure data models)
  Framework:      Pydantic v2 BaseModel, ConfigDict
  Imports:        uuid, datetime, timezone, Optional, List, Dict, Any

  class Entity(BaseModel):
    Description:  Base class for all domain entities
    Fields:
      id          str       Auto-generated UUID4 (default_factory=uuid4)
      created_at  datetime  UTC timestamp at creation (default_factory=utcnow)
    Config:       model_config = ConfigDict(extra="ignore")
                  — Strict mode; ignores extra fields during initialization
                  — Prevents accidental field injection from untrusted input

  class Note(Entity):
    Description:  Discrete unit of information stored in the Memory Lattice
    Extends:      Entity (inherits id, created_at)
    Fields:
      text        str             The note's text content
      tag         str             Classification tag for the note
      vector      Optional[List[float]]   Embedding vector (None until generated)
      metadata    Dict[str, Any]  Flexible metadata dict (default_factory=dict)
    Usage:        Created via memory service when cognitive processing produces
                  notable information; stored in Azure Cosmos DB
    Vector Notes: vector field populated by embedding service; enables semantic
                  similarity search for RAG (retrieval-augmented generation)

  class MemorySnapshot(Entity):
    Description:  Snapshot of the system's cognitive state at a point in time
    Extends:      Entity (inherits id, created_at)
    Fields:
      summary       str             Human-readable summary of cognitive state
      active_nodes  int             Count of active memory nodes
      entropy_level float           Cognitive entropy measurement (0.0 - 1.0)
      timestamp     Optional[datetime]  UTC timestamp (default_factory=utcnow)
    Usage:        Generated by cognitive orchestrator; enables temporal
                  snapshots of platform cognitive state for audit and analysis
